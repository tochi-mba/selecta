# LF12 — historical local-first remote-player prototype (superseded)

**Status: archived design note, not executable integration guidance.** The original
`feat/lf12-player-ui` implementation predated PR #84 / ADR-0485's browser-first
device architecture. On PR #64's working branch the older
`LocalFirstPlayer`, `useLocalFirstControl`, `adapter`, and their custom
`contracts`, CSS, isolated Vite fixture and `lf12` Playwright configuration
were removed because none was mounted by the current Cloud or business shell.
Its synthetic tests only exercised a superseded local-engine metadata protocol.

The historical implementation and original decisions remain accessible through
the earlier agent PR and Git history. Do not use this note as a source of live
API paths, rollout flags, or working test commands.

## Current, supported source-level locations

- `web/src/cloud/CloudTransportDock.tsx` selects the browser-first or
  historical hosted dock by the authoritative personal-workspace feature flag.
- `web/src/engine/LocalBrowserPlayer.tsx` and `BrowserAudioRuntime.ts`
  play locally selected media without an installed native engine.
- `web/src/cloud/lf-device-control/BrowserSessionPanel.tsx` and
  `web/src/cloud/lf-session/client.ts` implement the signed, scoped
  Cloud browser-device control contract.
- `src/selecta/lf_api/` implements the opt-in authenticated Cloud bridge,
  with migrations, workspace scoping and fenced command acknowledgements.
- `web/src/cloud/lf-mix-repair/liveBrowserPorts.ts` connects Studio to
  actual local media, basic playback and WAV rendering.
- `docs/review/br64-postmerge-integration-audit.md` contains the current
  integration gaps, physical-device caveats and release blockers.

Maintain the active `web/src/cloud/lf-session/client.test.ts`,
`web/src/cloud/lf-device-control/fence.test.ts` and browser engine/Studio
regressions rather than reviving the detached LF12 fixture. Old customers'
historical hosted playback must remain behind the migration and explicit
rollout/retirement gates. Never infer actual audibility or safe takeovers
from a Cloud lease, an AudioContext running state, or synthetic tests.
