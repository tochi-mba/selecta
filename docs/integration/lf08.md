# LF08 — locally fenced playback ownership

**Target:** ADR-0466. **Base:** docs/local-first-cloud-rearchitecture-20261113, commit 0c114859a4f2f13c264dcbd0cba2808d422a97da. **Owner:** src/selecta/lf_playback/**, tests/test_lf08_*.py and this integration note.

## What this branch implements

The old playback/session.py flow permits a server lease to expire and reassign the speaker without independently confirming that the old physical output is silent. A stale cloud heartbeat is never evidence that the old speaker has stopped. The new implementation is opt-in: it **does not** modify existing cloud playback compatibility routes or Agent 07's playback/commands.py, Agent 09's playback/zones.py, or Agent 12's UI files.

The new module provides:

1. **Typed contracts:** Scope, TransferRequest, Preflight, OutputObservation and EnginePort. Each handoff specifies a workspace/zone, actor, operation ID, idempotency key, expected owner generation, immutable recipe revision, required canonical recording occurrences and transitions, destination and expiry. No audio bytes, raw fingerprints, file paths or stems are transmitted.
2. **Durable coordinator:** SQLiteOwnershipLedger is a transactionally serialized journal, using BEGIN IMMEDIATE and unique-inflight constraints per workspace/zone. It prevents simultaneous Play Here attempts across tabs and local processes. Production controllers must use a **single shared linearizable authority**, not private per-controller SQLite databases.
3. **TransferCoordinator:** an explicit request → prepared → released → acquired → started protocol. Statuses aborted and blocked distinguish reversible failures before the old output is released from uncertain/unsafe conditions after release.
4. **Device-local fencing:** FencedLocalOutput persists a generation floor next to the device's physical output, independent of cloud leases. It rejects stale playback commands after restart and cloud backup restoration, and requires local hardware/output confirmation.
5. **LocalEngineRegistry:** an in-process EnginePort adapter for standalone deployment and tests; the production remote adapter is Agent 07's authenticated outbound control channel.

## Safety invariants and state transitions

The coordinator first probes the destination's physical silence and validates its engine health, local media permissions, hardware output, immutable recipe revision, exact N/N recordings (not title matches), all transition versions and freshness of verification. The destination performs its work **silently** before ownership can change. Failed or missing media preflight leaves the original speaker playing.

Next the source engine must stop/fade and confirm its **physical output is silent** with a device-local fence at the new generation and the current operation ID. Cloud lease expiry cannot replace these confirmations. If the old device is disconnected, its audibility is **unknown**, so takeover is blocked and the new device remains silent. If source release is known to have failed while the old source is still audible, the transfer is aborted.

Only after the old speaker's release is confirmed does the coordinator advance the authoritative generation and recheck destination readiness. It then acquires the target **silently** and verifies target ownership and fence before initiating audio. A true started state requires a physical output check, not merely a command accepted/queued/delivered acknowledgement. Do not claim a gapless physical cross-device handoff: a failed destination may leave a real audible gap, which must be reported.

All device operations must be idempotent by operation ID and generation, locally authenticated and bounded by timeouts. Two concurrent requests are serialized by a transactional CAS; any duplicate request with the same identity returns its existing result, whereas reused identifiers for altered payloads are rejected.

## Crash and partition recovery

- Before source release: a restarted coordinator retries the same operation and preserves original playback. Silent preparation must be idempotent.
- Crash after source stop but before coordinator journal commit: independently inspect the persistent local output fence and physical silence for **the exact operation**, then commit release. Never infer from expired heartbeat alone.
- Crash after release or acquire: only retry the original operation. Do **not** automatically restart the old device. If target audio cannot be proven safe or cannot start, mark blocked and surface a truthful playback gap.
- Source offline but possibly audible: refuse takeover, even if its cloud lease is expired. Reconnection uses locally persisted fences to reject outdated commands.
- Destination output, media or transition changes between prepare and acquire: re-run preflight; fail closed.
- Restored cloud backup or reordered commands: an engine's local generation floor is authoritative. A stale release or start cannot override it.
- Deadline before release: abort while preserving the old speaker. Deadline after release: block; no blind rollback.

**Manual/emergency isolation** is a physically verified on-site hardware interlock or disconnection that prevents old playback from auto-resuming. The EnginePort.manual_isolate and PhysicalAudioOutput.verify_hardware_isolation methods require independently checked hardware evidence; a UI checkbox, staff claim or expired cloud heartbeat is not enough. Recheck destination readiness before isolation. Blocked states are intentionally not cleared by remote force commands.

## Integration requirements for other agents

**Agent 01 (runtime):** implement PhysicalAudioOutput against actual selected OS/hardware audio output, hardware audibility probes, exclusive output locks and idempotent mute/prepare/start. Persist the local fence outside disposable audio caches. Boot code must never automatically resume an old fenced generation. Windows service and Linux venue implementations need persistent local storage.

**Agents 03 and 04 (catalogue/recipes):** resolve each canonical recording occurrence locally, including differing encodings, revisions, offline sources and transition artifact versions; provide exact, current Preflight data. Metadata-only cloud guesses cannot make a recording playable.

**Agent 07 (control):** authenticate workspace, actor role, zone, target and operation identity on every envelope. Apply short command expiry, replay protection, offline outbox and device credential rotation. Queue/delivery is not physical application. Implement EnginePort over outbound authenticated engine connections; do not expose a public local filesystem/media API.

**Agent 09 (venue):** enforce one local fence per physical output and exclusive zone-output mapping. A designated offline venue speaker retains local authority until safely silenced/fenced or physically isolated on-site. Implement local schedules, hardware isolation proofs and output resource arbitration.

**Agent 12 (player UI):** distinguish Play Here from Control Existing Speaker, show actual physical owner/device/output and generation, show per-device verified media readiness, and display pending, blocked, uncertain or audible-gap states accurately.

## Safe rollout and rollback

1. Retain existing standalone and cloud compatibility while shadow-reading local device ownership and physical readiness. Do not run legacy lease-based automatic takeover alongside new local-first ownership for the same workspace/zone.
2. Wire in Agent 01 hardware outputs, Agent 07 authentication, Agent 09 zone/resource authority and Agent 12 UI behind explicit capability/feature flags.
3. Before production enablement, independently verify Windows output control, Bluetooth disconnects, Linux zone outputs, multi-device and multi-tab races, offline venue speaker, 30-day network partition, stale generation, power loss, restored backups and physical audible/silent conditions. No commercial music is required for automated tests.
4. Rollback disables new transfers but preserves local fences and the verified current speaker. Never lower a generation or fall back to cloud lease promotion without direct physical isolation and owner reconciliation.
