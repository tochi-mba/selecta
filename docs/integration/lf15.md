# LF15 — Lucy metadata-only planning and local execution

**Branch:** feat/lf15-lucy
**Starting ADR SHA:** 0c114859a4f2f13c264dcbd0cba2808d422a97da
**Architecture:** ADR-0472; implementation is not a production cutover.

## Implemented

- New typed, versioned schema in src/selecta/lf_ai/contract.py. Hosted planning receives only explicitly allowlisted recording ID, title, artist, album, genre, BPM, key, energy, duration, year and bounded user text. Unknown fields, local paths, local fingerprints, raw audio, PCM, stems, lyrics, URL fields, encoded media and binary are denied before model calls.
- HostedLucyPlanner in lf_ai/service.py calls providers with an empty tool list, buffers and validates complete JSON output and rejects invented recording IDs, commands, URLs, readiness claims, unknown actions, excessive content and invalid schema. AI output is a suggestion, never a remotely executable instruction.
- Deterministic planning preserves offline music selection, with genre/BPM/energy/key-informed ordering. It never performs DSP, advertises unverified results and does not claim playback started.
- HostedBudget limits model input/output tokens, spend and timeout. Existing selecta.ai gateway controls authoritative account and plan entitlements. No local DSP jobs are metered here.
- LocalPlanExecutor in lf_ai/execution.py independently checks authenticated workspace/device/actor/revision/generation, exact fresh Agent 03 recording bindings and local approval for each suggestion. It refuses missing/candidate/stale recordings and has no arbitrary command, audio output, shell or playback operation.
- Cloud-mode Lucy in lucy/agent.py now goes through lf_ai/bridge.py, not the existing WeftAI audio tool dispatcher. Standalone local mode remains on its existing intelligent mixing path.

## Plan contract

A hosted model may return a JSON object such as:

~~~json
{
  "schema_version": 1,
  "summary": "Suggested ordering from music metadata",
  "steps": [
    {
      "op": "suggest_order",
      "recording_ids": ["rec-a", "rec-b"],
      "transition": "blend",
      "note": "Similar tempos"
    }
  ]
}
~~~

Only suggest_order, suggest_transition and explain are recognised operations. Each step must contain exactly op, recording_ids, transition and note; the envelope must contain exactly schema_version, summary and steps. The trusted host adds workspace_id and device_id. All plans carry availability=unverified until a local device checks actual media. A proposed mix is not a saved draft or playback command.

## External typed-adapter contracts

**Trusted cloud context (Agent 07 and cloud host):** register a sync or async app.lf_ai_metadata_context(conversation_id) callback after authenticating the conversation. It must return exactly workspace_id, device_id, catalogue_rows. catalogue_rows is an explicitly consented, tenant-scoped, maximum-48 list of allowlisted metadata dictionaries. Without this producer, cloud Lucy fails closed rather than inventing an available catalogue. No model may choose the workspace or device. Integrate future cloud control events as unverified plans rather than automatic commands.

**Agent 03:** implement LocalEnginePort.verify_exact(scope, recording_id) -> VerifiedRecording locally. Return only exact state, canonical ID, verification time and source revision. Never return path, fingerprint or binary. Candidate, alternate revision, source-disconnected, unsupported, missing, permission-required, blocked and unknown are NOT ready.

**Agents 05/07/08:** provide local authorise(scope, suggestion, approval_token) and apply_suggestion(scope, suggestion) adapters, rechecking actor rights, signed approval, source binding, owner generation, local policy and immutable recipe revision ATOMICALLY at commit time. Agent 05 retains DSP scheduling and local compute resource control. Real playback requires a separate host-issued confirmation; no AI suggestion may start it. Never expose a generic executor or arbitrary shell/URL/path capability.

**Agent 04:** map canonical recording IDs and stable occurrence IDs to immutable portable recipe revisions; do not confuse a planning suggestion with a committed recipe.

**Agent 16:** existing AI gateway manages account entitlements and billing. HostedBudget is only a per-turn guard and must not bill local analysis/render/seams/stems/export.

## Failure and parity

Provider errors, malformed output, timeouts, offline mode and exhausted hosted budgets produce a deterministic local music-order suggestion from safe metadata (or an honest empty-catalogue result). Cancelled runs do not turn into fallback executions. Existing standalone Lucy and its original intelligent proposals, manual editor and library are untouched.

**Not yet integrated outside Agent 15 ownership:** authenticated cloud context producer, final Agent 03/05/07 local adapters, remote UI rendering, persisted cloud recipe conversion and cross-device end-to-end verification. Treat these as final-integration blockers, not shipped capabilities.
