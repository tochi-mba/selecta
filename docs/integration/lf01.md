## Implemented interface

* Legacy SELECTA_MODE=local|cloud still defaults to local, and existing
  selecta web and developer API factories remain unchanged.
* modes.core exports RuntimeTopology, WorkspaceKind, EngineRole,
  Connectivity and runtime_topology(). These are orthogonal to Mode;
  cloud can never claim an audio-executor role, and a controller is not
  a local speaker. To keep existing modules untouched, import new symbols
  from selecta.modes.core directly.
* Local engine runs the **existing** selecta.api.serve() using a guarded
  127.0.0.1-only Uvicorn factory. Entry: selecta.local_engine.http:application.
  Manual lifecycle: selecta engine run (foreground), start (detached),
  stop, restart, status, config, capabilities, access-token, rotate-access.
  The supervisor owns a generation-bound lock, status heartbeat, stop request,
  append-only local logs, bounded crash restart/backoff and occupied-port
  refusal. API readiness is separate from physical audio readiness.
* Stable private state: Windows LOCALAPPDATA/Selecta/Engine; Linux
  XDG_STATE_HOME/selecta/engine (fallback ~/.local/state/selecta/engine);
  macOS ~/Library/Application Support/Selecta/Engine. Override with
  SELECTA_ENGINE_STATE_DIR. User music stays in the legacy SELECTA_HOME.
  Config writes are atomic; malformed config is quarantined, not executed.
* Local discovery: discovery.discover(state_dir) checks a fresh supervisor
  heartbeat and probes a single 127.0.0.1 port for matching service and
  random installation identity. Protocol version handshake is bounded to v1.
  There is no LAN broadcast, remote file server, pairing or cloud audio.
* Health: GET /api/local-engine/health (service, installation_id,
  protocol_min/max, api_ready, audio_ready, output_state);
  GET /api/local-engine/capabilities (allowlisted platform/FFmpeg/resources/
  codec/output facts). NO paths, fingerprints or audio bytes.
* Security: the installable API guard rejects non-loopback Host values,
  mismatched Origin, cross-site Fetch metadata and WebSocket origins.
  Browser mutations require exact same Origin; originless headless
  mutations require a local token via X-Selecta-Local-Token. Rotation
  revokes previous headless tokens without disclosing them via HTTP.
  Bind MUST remain 127.0.0.1; an authenticated outbound control channel
  belongs to Agent 07 and is not implemented here.
* Updates: verify Ed25519 signed canonical manifest; immutable checksum
  staging, deterministic rollout cohorts, activation intent and metadata
  rollback. Missing trusted keys fail closed. This is NOT an operational
  updater, no signing keys/installer apply/smoke rollback have been shipped.
* Packaging examples: Windows user login Scheduled Task and Linux user
  systemd unit. These launch the installed package, not a frozen/signed
  executable. macOS runtime/output remains unsupported.

## Critical correctness limitations

Output enumeration cannot guarantee physical speakers. Without a *fresh,
real output sample supplied by the trusted local playback owner*,
capability_report reports actual_audio_verified=false and audio_ready=false
even if sound cards and FFmpeg exist. There is currently no integrated
output sampling callback, so this branch does not claim deployable audio
readiness; Agent 08/09 must wire and validate physical output samples.
Likewise an HTTP 200 from the worker is only API readiness, not permission
to take over music or claim a venue is healthy.

A healthy process may report API ready while audio remains unavailable.
Supervisor log contents are device-local and must never be uploaded to the
control plane without explicit safe redaction. The local token is scoped
only to the host. An untrusted local user with the same OS account or
malware on the host is outside this loopback origin defense: permissions,
OS isolation and signed binaries require independent review.

The existing standalone selecta web path remains backward compatible and
does NOT automatically enforce the new loopback middleware. The installed
engine path is the guarded replacement; final integration needs a separate
assessment of whether legacy development and standalone middleware should
be migrated without breaking Vite proxy clients.

## Required integration wiring (owned by other workstreams)

1. pyproject.toml / wheel metadata: currently src/selecta is already the
   wheel package; ensure local_engine is included in wheel QA, pin an
   explicit cryptography dependency (currently indirect through PyJWT),
   and define Windows signed-installer and Linux package release jobs.
   Manifest changes intentionally not made in this branch.
2. Public imports: if consumers require selecta.modes.RuntimeTopology,
   export the new core types from modes/__init__.py after compatibility
   review; this file belongs to existing code outside LF01 ownership.
3. Agent 07: connect outbound authenticated device registration, key
   revocation and tenant/zone authority to engine health; never expose
   the local filesystem routes publicly.
4. Agents 08/09: provide trusted output-sample evidence and per-zone
   physical output/device routing. Do not turn audio_ready true from
   API health, OS device enumeration or browser AudioContext unlock.
5. Agent 05: source engine resource caps and model/codec provenance from
   the durable local work scheduler. Do not turn inferred codec presence
   into successful engine processing.
6. Packaging and release owner: provision real vendor signing keys,
   build reproducible Windows/venue artifacts, validate upgrade recovery
   and rollback on hardware, then enable rollout only with verified keys.
7. Final integrator: discover tests/test_lf01_*.py through existing pytest
   tests directory, check static typing and Ruff, run Windows 3.12 and
   Linux systemd integration jobs; verify macOS unsupported UX truth.
8. Existing cloud API/routes and account-free standalone are intentionally
   retained. Do not reinterpret this branch as permission to remove them.

## Test matrix

Focused tests under tests/test_lf01_*.py cover old-mode compatibility,
cloud controller-only, workspace dimensions, config corruption and
permissions, credentials rotation, DNS rebinding/CSRF, stale output evidence,
FFmpeg absence, unsupported macOS, incompatible protocol versions, port
collision, stale lock, worker crash restart budget, generation-scoped stop,
offline/reboot heartbeat, rejected/tampered updates, staged activation and
metadata rollback. Physical audio, Windows service creation, Linux headless
six-hour soak, binary update/rollback and independent security review remain
unverified release gates.

Run: python -m pytest -q tests/test_lf01_*.py
No ADR checklist task is ticked in this parallel branch; integration and
independent verification must occur before implementation statuses change.
