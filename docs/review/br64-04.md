## Implemented, within Agent 04 ownership

1. `web/src/dsp/neural/registry.ts`: machine-readable per-checkpoint audit, native status vs browser redistribution approval, intended backends, cache/peak/latency/quality **unknowns kept null**, explicit blockers. All four native model families are honestly non-shipping; `small0` and `final0` remain separate.
2. `select.ts`: fail-closed selection using live per-device backend evidence, exact checkpoint checksum, memory and quality-gated performance results. Phones and iPads are candidates, not auto-excluded. Missing evidence yields `non_neural` fallback. Current built-in audit intentionally makes every model unavailable.
3. `ortBridge.ts` + `runtime.ts`: actual ORT Web `InferenceSession.create`/`run` adapter with injected runtime, typed tensors, output validation, session cleanup, no synthetic model outputs, WASM/WebGPU explicit selection, runtime cancellation checks and injectable playback-first memory lease. **No weights, compiled ORT package or production invocation wired**: supplying a valid *tested* graph and build remains integration work.
4. `checkpoint.ts`: same-origin only, relative-to-origin absolute path, SHA-256 integrity checked before use, redirect disabled, bounded-size streamed download and optional cache with eviction tolerance; abort checks and corrupted-cache refetch. **Current digest implementation buffers the complete model for browser SubtleCrypto**; >512 MiB files are excluded and its transient memory overhead must be benchmarked. A malicious network origin cannot be specified as an asset URL.
5. `benchmark.ts`: independent, on-device warm-up and 3-run timing harness for a supplied real checkpoint and fixture (returns no quality clearance). It has NOT been executed against real weights or phones.
6. `stemWindows.ts`: bounded transition-focused window geometry with overlap/crop instructions for future separation. **Not a Demucs port**; no claim of valid overlap-add, phase, padding, seam sound or source quality.
7. `wordSafety.ts`: refuses guessed timings and unverified forced alignment; even acoustic output needs a checkpoint-bound, independently checked, calibrated score and named evaluation. **No actual forced-alignment model exists in browser yet.**
8. `web/src/ai-dsp/cloudPlan.ts` and `lf_ai/browser_capabilities.py`: strict hosted Lucy proposal parsing and independently derived browser capability requirements, scope/actor/generation/revision, exact local recording preflight, permission and non-executing recommendation. Cloud planner cannot prescribe downloaded models or local sources. Existing `lf_ai/contract.py`, `execution.py`, provider and native WeftAI pipeline remain unchanged.
9. Focused unit/contract tests in `neural.test.ts`, `checkpoint.test.ts`, `cloudPlan.test.ts`, `tests/test_br64_04_browser_capabilities.py`; Playwright `web/e2e/br64-04-neural.spec.ts` is a **contract skeleton** only, not real phone/tablet evidence.

## Unimplemented / release blockers

**None of Beat This, S-KEY, HTDemucs or wav2vec2 is browser-implemented and tested.** To advance any one, obtain lawfully redistributable checkpoint and licence signoff; export frozen verified ONNX; reproduce preprocessing and outputs; pin SHA-256 and distribution path; enumerate graph ops per WASM/WebGPU, with an unsupported-GPU fallback; benchmark actual iPhone/iPad/Android midrange and laptop devices including decoded audio and *actual peak browser memory*, memory pressure, battery and thermal drift; compare with native oracle on licensed fixtures and independent listening/timing gates. Record versioned latency, accuracy, energy, source/seam quality and cache size before changing registry status.

- *Beat This*: graph+log-mel/postprocess conversion, fine beat phase/refinement validation. Prioritize `small0` for mobile evaluation, not presumed success.
- *Key*: cannot distribute existing S-KEY research checkpoint in paid Cloud; find/retrain a separately cleared model or use Agent 03's clearly labelled deterministic chroma approach.
- *Stems*: ONNX operator support and significantly constrained-memory 15–30 s window handling, overlap/context and quality evaluation unknown; no assumption of whole-song cost parity. If unavailable, offer non-stem transitions and recipe editing.
- *Words*: wav2vec2 model export, transcript/rights source, local inference, CTC alignment plus **independent unguided check**. Never claim guessed word edges safe.
- *Runtime*: integration must ship exact audited ORT Web/WASM artifacts (and optional WebGPU build), in dedicated workers off the AudioWorklet thread. ORT session `run` is not physically interrupted by AbortSignal; cancellation between calls is checked, but hard preemption requires worker termination. GPU device lost returns an explicit failure; optional explicit *revalidated* WASM retry not yet provided. Caches/OPFS quota, eviction, COOP/COEP/threads, browser power and real output remain integration acceptance gates.
- *Cloud*: audit authenticated egress in all routes/logging/telemetry; this PR validates Lucy's narrow plan and source metadata interface but does not certify global Cloud routes.
