# BR64-05 — Browser-local mix render and export review

**Starting point:** `0c7d321d9005c507ba7adde30b15e70289e357b3`, branch `feat/br64-05-render-exports`. Scope: Agent 05-owned paths only. **Architecture:** PR #84 ADR-0485 and browser-first master plan. No Python, FFmpeg executable, Cloud PCM upload or edits to other agents.

## Implemented in this branch

- `web/src/render/contracts.ts` — portable immutable recipe/source adapter contract, exact recording-revision checks, versioned DSP adapter identity and SHA-256 local artifact identity.
- `web/src/render/chunks.ts` — bounded planar PCM windows, integer-frame placement, overlapping clips and equal-power edge fades, mono/stereo conversion, explicit cancellation and cooperative event loop yield; exact true-duration frame count. This is a **core gain/crossfade renderer**, not parity for all historical Selecta DSP.
- `web/src/render/offline-preview.ts` — at most 10-second bounded OfflineAudioContext preview. It is deliberately **not** used to render long mixes into one AudioBuffer.
- `web/src/export-codecs/` — real RIFF PCM16 WAV with 4 GiB guard, and native FLAC stream with STREAMINFO + verbatim 16-bit subframes and CRC8/CRC16; no external encoder licence or mislabeled WAV. FLAC is lossless but **not compressed**. STREAMINFO MD5 is unspecified; CRC32 + frame CRC readback checks are provided. Advanced compression is a future independently benchmarked WASM adapter.
- `web/src/local-artifacts/` — OPFS staging + validation + manifest-last cache publish, 2.2x storage reserve, quota pressure, cancellation cleanup, read-back CRC, separate user-initiated local save/download/share, no browser Cloud transfer. Cache entries are not user-saved exports. Origin storage can be evicted.
- `web/src/render/export.ts` — orchestrated local render, exact progress states, single-job dedup, active speaker priority; checks actual APIs, not mobile user-agent. No model inference.
- `web/src/render-ui/` — accessible self-contained progress/format/storage panel for Agent 07 to mount. Existing Studio unchanged.

## Interfaces required from other agents

1. **Agent 02**: supply a `RenderSource.read(startFrame, frames, sampleRate, signal)` streaming/windowed local decoder. Must return *exactly* requested sample frames at output rate, with revision fencing and no media upload. `audioBufferSource` is supplied solely for already-small RAM-backed media.
2. **Agent 03**: port DSP into `RenderProcessor.process(planarChannels, absoluteStartFrame, AbortSignal)`; maintain stable state/phase across chunks. Do not reset a filter at every chunk; implement lookbehind/lookahead/overlap-save at adapter level.
3. **Agent 04**: only model-verified local neural processors implement the adapter with `modelHash`; absent capabilities must be blocked and shown as `model_unsupported`, never sent to Cloud.
4. **Agent 07**: mount `RenderExportPanel` with recipe, sources, playback state and user-safe filename. It intentionally makes no direct Studio changes.

## Safety and limitations

- Strictly local OPFS; if unavailable, rendering must fail with storage capability guidance. Source files/originals and downloaded exports are never deleted during cache cleanup. No cross-device audio transfer. No PWA/native installer assumptions.
- Work currently executes in small main-thread tasks and yields between chunks. Integration should move long-running DSP/decode to a Worker and benchmark foreground audio underruns; active playback currently blocks export as the safe default.
- A finished encoder writes an artifact to OPFS and validates size/header/checksums. The manifest is written last; a browser crash may leave an unlisted cache orphan that can be explicitly cleaned. OPFS lacks a universally portable atomic rename.
- Pickers are user initiated. When a platform lacks `showSaveFilePicker`, small file share/download is offered; larger outputs remain local in OPFS with a truthful save limitation. No promise of background processing or guaranteed persistent storage.
- FLAC only 1/2-channel 16-bit 8–192 kHz; no MP3/AAC export. Historic effects, beat warps, limiter, neural stems, wordplay and advanced seam quality are **not claimed implemented** here.
- No actual iPhone, iPad, Samsung Galaxy, Android tablet, thermal/battery or six-hour venue device benchmark has been conducted. Phone is not rejected by form factor, but not certified for a specific device.
- Device test matrix (pending hardware): Chrome/Edge desktop, macOS Safari, Firefox; iPhone Safari tab/PWA; iPad Safari tab/PWA older A-series and M-series; Samsung Internet and Android Chrome low/mid/high-memory phones/tablets; Android Firefox. For each, record exact hardware/OS/browser, codecs, permitted file access, max duration, storage/eviction, memory, battery/thermal, resume, audible output and actual decode latency.
- **Verification gate:** run `cd web && pnpm build && pnpm test -- src/render/chunks.test.ts src/export-codecs/codecs.test.ts src/local-artifacts/store.test.ts src/render-ui/RenderExportPanel.test.tsx && pnpm exec playwright test e2e/br64-05-render.spec.ts`. Browser emulation tests are API/viewport smoke, never hardware certification.

## Operational checkpoints and recovery

Checkpoint/resume is **not offered**: partial jobs are explicitly invalid; retry starts a new bounded render with the same versioned identity. This avoids unsafe reusing of stale/changed decoder, DSP/model or recipe revisions. A complete cached artifact must pass read-back validation before reuse. The UI distinguishes preparing, rendering, cancelled, paused, interrupted, storage pressure and validated completion. Missing model/codec adapters require explicit integration-gated failures.
