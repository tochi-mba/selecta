Before prices are locked, ask beta members Sean Ellis's question, 'How would you feel if you could no longer use SelectaDJ?'. Superhuman used 40% 'very disappointed' as its bar. Also hold short willingness-to-pay conversations (Ramanujam, Monetizing Innovation): what would you pay, for which feature, compared with what. A near-100% yes with no pushback means the price is too low. Claude can build the survey page and tally if wanted; the conversations are the owner's.
