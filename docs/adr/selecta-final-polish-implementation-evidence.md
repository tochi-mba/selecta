## Evidence recording contract

For *each* task record: exact requirement; source path/range; implementing PR and SHA (or accepted source reconciliation), passing automated test run on that SHA, available real-music/real-device/assistive-technology results, named independent reviewer, date, OS/browser/device/zoom/theme, participant/task denominators for usability, negative cases, defects and rollback. Evidence may not be inferred from a planning document or earlier programme snapshot.

**Implementation status and verification are separate:** A reviewer can approve a design specimen without any code having been implemented; source presence is not independent QA. On an accepted implementation PR, update both this ledger and the machine-readable file. Historical SF/GP ledgers must retain their original baselines.
