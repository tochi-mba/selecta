## Status transition and negative-case rules

Every checkbox remains unchecked until independent evidence, even if code is source-present. No task can be set to Implemented without linked source change/reconciled exact source evidence, passing relevant tests and SHA. No task can be independently Verified on CI screenshot evidence alone.

Test Light/Dark/System and forced colours; 320px to 2560px, shallow landscape and 400% zoom; long/Unicode/RTL/duplicate titles; 20k Library and 64-cell Studio; no data, loading, failed, offline, stale and cancellation; keyboard/touch/NVDA; Still/reduced motion; hardware/audio continuity where relevant.
