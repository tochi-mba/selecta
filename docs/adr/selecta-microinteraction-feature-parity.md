## No-regression contract

1. **Local music and privacy:** never mutate original music; keep localhost security/path protections and truthful LRCLIB metadata disclosure, with no new cloud, app telemetry, native desktop installer or folder bridge.
2. **Audio authority:** only one audible owner, reliable manual Pause, Stage/player continuity across routes, preview release without double-playing.
3. **Creative scope:** stable current/draft/revision identity, exact seam keys, optimistic mutation guards and scoped Undo; no stale callback overriding newer intent.
4. **Request safety:** visible extra bridge songs, explicit approval, exactly atomic route insertion or no insertion; no unconfirmed playback promise.
5. **Power capability:** all eight outgoing/incoming Voice/Drums/Bass/Melody lanes, Shape/Grid/List, keyboard alternatives, 8–64 cells, honest preview.
6. **Research and artifacts:** condition-anonymous listening study, idempotent answer, frozen-revision FLAC which decodes and matches its source.
7. **Platform and task routes:** browser-first local server, existing aliases, deep links, command palette, media keys, Library source management, diagnostics, source-watch and preferences retained.
8. **Honest status:** planned/queued/rendering/ready/fallback/failed and objectively measured/human-liked remain separate, with no fake beat/alignment/quality.

At implementation time, reconcile each touched behavior to [existing experience parity](selecta-experience-feature-parity.md), [4.0 parity](selecta-4-feature-parity.md) and the exact source/test SHA rather than inferring all older work is complete.
