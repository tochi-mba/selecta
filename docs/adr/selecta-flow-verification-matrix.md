## Required dimensions

- **Audio/music truth:** actual local tracks and rendered transitions including cut, blend, wordplay and stems; silence, Pause, interrupted preview, limited seeking, media keys and hidden tabs.
- **Accessibility:** NVDA/Edge, keyboard-only, high contrast/forced-colors, screen-reader status volume, pointer/touch/stylus, reduced motion, 320px reflow and 400% zoom.
- **Data and correctness:** ready/missing/unknown states, duplicate titles and song occurrences, current/draft version races, atomic consented bridges, Studio diff/recovery, exact frozen FLAC and original files unchanged.
- **Visual:** dark/light/system, no artwork, very long and RTL titles, each loading/error/empty state, full-screen refusal, 15 actual spectrum styles and approved candidate screenshots.
- **Hardware/performance:** named devices and OS/browser, 20k Library, 100-song Create, 64-cell Studio and render/analysis during playback; report measured INP/CLS, input latency, memory and audible dropouts.
- **Research:** uncoached first mix, real handoff, shape, audition, Studio, requests, search, export and recovery with denominator, completion, comfort, joy and errors. Blind A/B stays visually neutral.

**Verdict:** NO-GO for *the new 400-task redesign programme* pending implementation and independent acceptance, not a claim the current app is unusable. [Release gates](selecta-flow-release-gates.md).
