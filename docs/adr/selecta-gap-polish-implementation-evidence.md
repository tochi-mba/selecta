## Evidence rules

Implementation and independent verification are separate. Source code/test evidence with exact PR/SHA allows Implemented, while a named external reviewer with browser/device, real audio and actual task outcomes permits Verified. Missing evidence is not evidence that an existing feature is absent. Historic SF/MI/CI work is to be reconciled, not retrospectively rewritten.
