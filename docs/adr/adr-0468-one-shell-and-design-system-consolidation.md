## Context and evidence boundary

Three audits on PR #96 (a design-system inventory, a micro-interaction walk of every surface and research on the craft) agreed that the local app had a mature token system, shared primitives and guard tests, while the Cloud, Rooms, devices and guest surfaces largely bypassed them: `cloud.css` had dozens of raw font sizes, 12 raw radii, lime used as text and its own rail; there were five `window.confirm` sites, many ad-hoc progress bars, three screen-reader-only classes, undocumented breakpoints and no exit animations; and the guard tests' scopes quietly excluded the sheets that broke the rules. The owner also hit two live defects importing a 2,898-file library. The owner gave full reign to redesign any surface and chose to unify hosted Cloud onto the shared shell behind a flag, not to reach visual parity with a second shell.

This ADR records the decisions the overhaul (waves W0 to W7 on PR #96) made and what is true at the branch head named above. Unit tests named below were run at that head where the line says so; Playwright specs are present but their runs are pending unless a line says otherwise.

## Decision

- **One shell.** Hosted Cloud accounts are drawn by the shared shell (`Shell`, manifest and router) behind the new release flag `cloud.hosted_shell`, with the hosted pages as its children and the account places in More exactly as the local-first shell has them. The shell gets a null player facade and the `CloudTransportDock` sits in its dock slot, so no engine, media store or DSP enters the hosted bundle. With the flag off the legacy rail renders byte for byte as before. The legacy rail retires in a later PR once the flag has baked through the ADR-0467 rollout.
- **One token hierarchy and one type scale.** Palette, meaning and parts layers live only in `tokens.css`; components never name the palette. One Light palette serves both Light switches. The type roles are the only font sizes outside `tokens.css`, with three roles added for Cloud and Rooms (`--type-hero`, `--type-figure`, `--type-eyebrow`). Every feature sheet moves onto meaning, type and radius roles.
- **Guest and display palette exception.** The Rooms guest page and the big-screen display keep their own small token blocks because they load without `tokens.css` to stay inside their bundle budgets. Every value in those blocks is copied from the `tokens.css` token of the same name, with the source named beside it, and a drift guard fails when they disagree.
- **Canonical breakpoints, named exceptions.** Six widths (480, 640, 768, 900, 1100, 1400) are defined once in `web/src/styles/breakpoints.ts`. Every other width still in a sheet is named in `LEGACY_WIDTHS` with the canonical width it moves to and the register row or component that pins it, so moving one is a deliberate change, not drift.
- **Exit-motion protocol.** A closing overlay, toast, menu, tooltip or popover sets `data-closing`; the sheets animate it at the `--motion-exit-*` tokens (dialog fade and 2% shrink, drawer and sheet slide out, toast fade and 4px drop, menu fade); JavaScript unmounts on `animationend` with a timeout of the token's length as the fallback. Reduced motion swaps every exit for a short fade, never removes it; Still and low power take it to nothing.
- **Destructive actions confirm on the shared stack, with undo where honest.** `ConfirmDialog` replaces `window.confirm` and hand-rolled confirmations: focus trap, inert page, focus return; a reversible removal says so and confirming shows the 15 second Undo toast that Activity keeps; an irreversible one says plainly that it can't be undone and puts focus on the safe answer.
- **Progressive import.** Behind `cloud.progressive_import`, a folder import keeps running while the member moves on: onboarding unlocks as songs land, a shell chip shows progress, milestones are announced (started, each quarter, finished) and an interrupted import offers to carry on.
- **PWA install and storage persistence (owner-approved 2026-11-18).** The Cloud site ships a web app manifest; SelectaDJ requests `navigator.storage.persist()` from a user gesture (after the first finished import, and from a button on the This-device storage card) and shows the granted state honestly; install surfaces capture `beforeinstallprompt` on Chromium and give Add to Home Screen guidance on iPadOS, behind the existing surfaces' flags.
- **Guards keep it true.** The style guards walk every sheet, the gallery shows every `ui/` export (checked by a completeness test), and new bans cover `window.confirm`, glyph icons, raw `setInterval` outside the polling policy, hidden-input pickers without a keyboard path, em dashes in user copy and new docs, widths outside `breakpoints.ts`, and guest/display palette drift.

## User outcome and acceptance contract

Every SelectaDJ surface, local or Cloud, hosted or local-first, looks, moves and confirms the same way, and the tests fail the moment a sheet or component drifts from the system. A hosted member sees the same navigation as a local-first member; nobody meets a browser `confirm` box, a dead control, an unlabelled progress bar or a close that snaps.

## Edge cases

- **Hosted account with `cloud.hosted_shell` off.** The legacy rail renders unchanged; nothing in the shared shell is fetched.
- **The server's snapshot does not mention the flag.** The shared shell is drawn only when the account's features say `cloud.hosted_shell` true and the registry flag is on, never because an answer left it out.
- **A hosted page fails to render.** Each page sits in its own `Section`, so the frame, navigation and the other pages stay.
- **Reduced motion while a menu closes.** The exit must still read as leaving (the swap fade); see BF-0468-04 for the current gap.
- **A destructive action fails.** The dialog stays open and the confirm button shows the failure; nothing claims it happened.
- **The browser refuses persistent storage.** The storage card keeps the may-clear wording; SelectaDJ never claims persistence it was not granted.
- **The guest page or display drifts from `tokens.css`.** The drift guard fails before the colours reach a phone or a big screen.

## Rejected alternatives

- **Visual parity for the legacy Cloud rail.** Two shells styled alike still diverge in navigation, focus and frame behaviour; one shell removes the class of bug.
- **Removing the legacy rail in this PR.** The flag must bake first; flag off must stay byte-identical until then.
- **Making guest and display load `tokens.css`.** Breaks their bundle budgets; copied values with a drift guard keep one palette at a fraction of the size.
- **Removing exit animations under reduced motion.** A closing thing that vanishes instantly reads as a glitch; a short fade is the accessible swap.
- **Keeping `window.confirm`.** It is not themed, not inert-aware, steals focus unpredictably and can't offer Undo.

## Governance

Accepted by the owner on 2026-11-18, including the PWA install and storage-persistence scope. A change to the type scale, the canonical breakpoints, the exit tokens or the confirm copy is made once (in `tokens.css`, `breakpoints.ts` or `CONFIRM_COPY`) and the guards re-run, never per surface. New user-visible parts keep the owner rules: a registered flag with clean reflow when off, SelectaDJ in user copy, no em dashes, files at or under 1000 lines.

**Operational note: the 2026-11-18 corruption incident.** On 2026-11-18 foreign commits on the PR #96 branch emptied 32 files. `91c1d666` rebuilt what they destroyed (the reauth `changed` lapse state, a sweep remembered against the store's availability revision, a resolver that hashes the bytes it hands the engine, the shell's media request read through a ref), stepped back what existed only in the emptied files (recipe drafts and the local export panel) and removed three files that were only ever empty, including an empty migration that stopped every database from starting. Since the repair, recipe drafts have come back in a different form: saved browser recipes are listed in My Mixes and can be made the current mix (`fb6bf587`, `f75dbb63`, `db5959f1`, `e76a65c5`), and the server gained recipe duplicate and delete (`3e7eede2`); the removed drafts migration was not reinstated. The local export panel is still stepped back (`localExport` is `null` in `web/src/cloud/LocalFirstShell.tsx`; `web/src/cloud/LocalExport.tsx` does not exist). Every agent working on the branch now follows a corruption guard in its rules: never `git add -A` or `git commit -a`, stage only the exact paths changed, and refuse to commit when a staged file is empty or unexpectedly binary.
