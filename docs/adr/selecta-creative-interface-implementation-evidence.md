## Status promotion and evidence schema

Record for every task: dated owner decision, accepted ADR, actual source PR and exact merged SHA, target tests, dark/light/forced-color screens, pointer/keyboard/AT/touch and zoom, reduced-motion equivalent, real audio and playback owner where applicable, error/stale/undo proof, named reference hardware and performance trace, reviewer/date/pass/fail, and preservation of revision/bridge/source-file/FLAC invariants. Human verification is separate from code completion.

Each task moves individually from Not started to In progress with a named implementing PR, then Implemented only after merged code and tests, then independently Verified only after the applicable recorded human/real-device/real-audio evidence. Reconcile the prior MI task before claiming a new CI delta was completed. Update this ledger, ADR, checklist, roadmap and release gates together.
