Each packet is built from the automated evidence, carries the source SHA and leaves reviewer, date and every verdict blank. A packet is never verification: `check` refuses an automation as reviewer and any unresolved P0.

Build one: `python -m selecta.audit.fp_review_packets build <task> --out <file>` (add `--contrast <fp-0264-boundary-contrast.json>` for FP-0264-08, and `--manifest <file>` per paired manifest for FP-0271-08). Fill it in, then `python -m selecta.audit.fp_review_packets check <file>` lists what is missing. Study packets take `records`: one row per participant and task with `participant`, `group`, `phase`, `task`, `seconds`, `success` and `false_beliefs`; use no names.
